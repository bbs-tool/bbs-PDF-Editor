# 입장·이용 기록 서버 설정 (Google 시트 + Apps Script, 무료)

GitHub Pages는 파일만 보여 주는 곳이라 데이터를 저장할 수 없습니다.
그래서 입장 코드 확인과 이용 기록은 **내 구글 시트**에 붙인 작은 프로그램(Apps Script)이 처리합니다.
한 번만 설정하면 되고, 비용은 들지 않습니다. (일반 구글 계정 무료 한도로 팀 규모 사용은 충분합니다)

## 무엇이 기록되나요

| 시트 | 언제 | 내용 |
|---|---|---|
| 입장기록 | 입장 팝업에서 코드를 맞게 입력했을 때 | 시각, 사용자 ID(브라우저마다 다름), 이름, 관리자에게 한마디, 코드 버전 |
| 이용기록 | PDF 저장·이미지 저장이 끝났을 때 | 시각, 사용자 ID, 이름, 종류(pdf/image) |

편집하는 파일 내용은 보내지 않습니다. 입장 팝업에도 이 안내가 적혀 있습니다.

## 설정 순서 (약 10분)

### 1. 구글 시트 만들기
1. <https://sheets.new> 에 접속해 새 시트를 만듭니다. 이름은 예: `PDF 편집기 이용기록`
2. 위 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.

### 2. 코드 붙여넣기
1. 열린 편집 화면의 `Code.gs` 내용을 모두 지우고, 이 폴더의 **`Code.gs` 내용 전체**를 붙여 넣습니다.
2. 맨 위 입장 코드를 원하는 값으로 바꿉니다. **처음 한 번만 쓰이고, 이후에는 관리자 화면에서 바꿉니다.**
   ```js
   const INITIAL_ENTRY_CODE = '0000'; // 처음 입장 코드
   ```
3. 💾 저장(Ctrl+S)

> 관리자 인증 코드는 **이 스크립트를 배포한 구글 계정의 메일**로 갑니다. 관리자 본인 계정으로 배포하세요.
> 메일 주소를 코드에 적지 않으므로 GitHub에 공개되지 않습니다.

### 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 설명: 아무거나 (예: `v1`)
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** ← 이용자들이 구글 로그인 없이 입장하려면 꼭 이것
4. **배포** → 권한 요청이 나오면 **액세스 승인** → 관리자 본인 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → 허용
   - 내가 만든 스크립트가 **내 시트에 쓰고, 내 메일로 인증 코드를 보내는** 권한을 묻는 것이라 괜찮습니다.
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

### 4. 편집기에 주소 넣기
1. `js/config.js` 를 메모장으로 열어 주소를 넣고 저장합니다.
   ```js
   export const TRACKING_URL = 'https://script.google.com/macros/s/…/exec';
   ```
2. GitHub Desktop에서 **Commit → Push origin** 으로 배포합니다.

### 5. 확인
1. `https://<내 아이디>.github.io/pdf-editor/` 접속 → 입장 팝업이 뜨는지 확인
2. 이름, 입장 코드, 한마디 입력 → 입장 → PDF 저장
3. 상단 **[관리자 모드]** → "안녕하세요, BB님 인증을 진행해 주세요" → **[인증 코드 받기]**
4. 메일로 온 6자리 코드 입력 → **[관리자 화면 열기]** (새 탭) → 이용 현황에 내 이름이 보이면 완료
5. 구글 시트에도 `입장기록`, `이용기록` 탭이 생기고 줄이 쌓입니다.

## 관리자 인증
- [관리자 모드]를 누르면 배포한 구글 계정 메일로 **6자리 인증 코드**가 갑니다 (10분 유효, 5번까지 입력 가능, 1분에 한 번 재발송).
- 인증하면 그 브라우저에서 **6시간** 동안 다시 인증 없이 관리자 화면을 열 수 있습니다. [로그아웃]하면 바로 끝납니다.
- `admin.html` 주소로 직접 들어가도 같은 인증 화면이 나옵니다.
- 화면에 보이는 호칭 "BB"는 `js/config.js`의 `ADMIN_NAME`에서 바꿀 수 있습니다.

## 관리자 화면에서 할 수 있는 것
- **입장 코드 변경**: 바꾸면 모든 이용자가 다음 접속 때 입장 팝업에서 새 코드를 입력해야 합니다.
- **이용 현황**: 일별·주별(월~일)·월별·연별 이용자 수와 명단 — PDF·이미지 저장을 완료한 사람 기준, 같은 사람은 한 번만 셉니다.
- **이용자 목록**: 이름, 관리자에게 한마디, 처음/최근 입장, 최근 저장

## Code.gs를 고친 경우
배포 → **배포 관리** → 연필(수정) → 버전: **새 버전** → 배포. (주소는 그대로 유지됩니다)
'새 배포'를 다시 만들면 주소가 바뀌니 `js/config.js` 도 바꿔야 합니다.

## 알아두실 점
- **가벼운 출입 관리입니다.** 웹 개발을 아는 사람은 브라우저 개발자 도구로 팝업을 우회할 수 있습니다. 지인·팀 공유용으로는 충분하지만 보안 장치는 아닙니다.
- 입장 코드는 Apps Script의 '스크립트 속성'에 저장되어 GitHub에 공개되지 않습니다.
  (Apps Script 편집기 → 프로젝트 설정 → 스크립트 속성 `ENTRY_CODE`에서도 직접 보고 고칠 수 있습니다.)
- 인증 메일이 안 오면 스팸함을 확인하세요. 구글 무료 계정은 스크립트 메일을 하루 100통까지 보낼 수 있습니다.
- 이미 입장한 사람은 기록 서버에 잠시 연결이 안 돼도 편집기를 계속 쓸 수 있습니다. 처음 입장하는 사람은 서버 연결이 필요합니다.
- 사용자 구분은 브라우저 기준입니다. 같은 사람이 PC와 휴대폰에서 쓰면 두 명으로 셉니다. (목록에서는 이름으로 구분할 수 있습니다)
- 기록 시트의 줄을 지워도 됩니다. 관리자 화면은 시트에 남은 내용으로 계산합니다.
- `js/config.js`의 주소를 비워 두면 입장 팝업 없이 누구나 쓸 수 있습니다 (내 PC에서 시험할 때).
