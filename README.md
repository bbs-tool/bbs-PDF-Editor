# BB's PDF Editor

브라우저에서 PDF와 이미지를 합치고, 순서를 바꾸고, 텍스트·도형·이미지를 올려 다시 PDF로 저장하는 편집기입니다.
서버 없이 브라우저 안에서만 동작하므로 **비용이 들지 않고, 파일이 외부로 전송되지 않습니다.**

## 주요 기능

| 구분 | 기능 |
|---|---|
| 불러오기 | PDF, PNG, JPG, WEBP, GIF, BMP (여러 개 동시, 끌어다 놓기, Ctrl+V 이미지 붙여넣기) |
| 긴 파일 | PDF 최대 크기(5080mm = 200인치)를 넘으면 A4 비율 또는 최대 길이로 페이지를 나눠 불러올지 물어봄. PDF 저장 때 다시 한 페이지로 합치기 가능 |
| 페이지 | 드래그로 순서 변경, 빈 페이지 추가, 복제, 90° 회전, 삭제. 체크 상자·Ctrl/Shift+클릭으로 여러 페이지 선택, 전체 선택·선택 삭제·전체 삭제 |
| 규격 | A4 / 원본 크기 유지 / 이미지 크기에 맞춤 / 영역 직접 지정(mm), 세로·가로. 이미지 크기에 맞춤·영역 직접 지정은 상하좌우로 영역 추가(mm) |
| 배치 방식 | 비율 유지 맞춤(여백) / 꽉 채우기(일부 잘림) / 늘이기, 가로 정렬(왼쪽·가운데·오른쪽)·세로 정렬(위·가운데·아래) |
| 설정 일괄 적용 | 지금 페이지의 페이지 설정을 모든 페이지 또는 왼쪽 목록에서 선택한 페이지에 적용 |
| 요소 | 텍스트, 네모, 동그라미, 이미지 겹치기 — 불러온 PDF·이미지 포함 마우스로 이동·크기·회전. 왼쪽 페이지 썸네일로 끌어 놓으면 그 페이지로 이동 |
| 도형 그리기 | 네모·동그라미 버튼을 누른 뒤 페이지 위를 끌면 그 위치·크기로 생성 (PPT 방식). 클릭만 하면 그 자리에 기본 크기, Shift: 정사각형·정원, Esc·버튼 다시 누르기: 취소 |
| 모자이크·블러 | 버튼을 누른 뒤 가릴 영역을 끌어서 지정. 모양(네모·동그라미), 효과(모자이크·블러), 강도(10~100%, 25·50·75·100% 빠른 선택)를 오른쪽 패널에서 변경. 저장 시 그 페이지는 가린 원본 글자가 남지 않도록 이미지로 합쳐짐(PDF 300dpi) |
| 공지사항 | 오른쪽 아래 동그란 버튼 → 공지 목록 → 누르면 내용. 안 읽은 공지가 있으면 빨간 점·N 표시. 관리자 화면에서 등록·수정·삭제 |
| 이미지 넣기 | 페이지가 있을 때 이미지를 넣으면(버튼·끌어다 놓기·Ctrl+V) 현재 페이지 위 / 새 페이지 중 선택 |
| 우클릭 메뉴 | 자르기·자르기 원래대로(PDF·이미지), 복사, 복제, 맨 앞/뒤로, 잠금, 삭제 |
| 겹침 | 레이어 순서(맨 앞·앞·뒤·맨 뒤), 투명도, 회전, 잠금 |
| 편집 | 실행 취소/다시 실행, 요소 복사·붙여넣기·복제·삭제, 확대·축소 |
| 폰트 | Pretendard(기본 포함), 맑은 고딕(PC에서 불러옴), TTF·OTF 직접 추가 |
| 템플릿 | 고른 페이지(예: 1-3, 5)의 텍스트·도형·이미지 배치와 페이지 설정을 저장해 두고, 현재 페이지부터 순서대로 또는 모든 페이지에 불러오기 (브라우저에 보관) |
| 안내 | 처음 열면 버튼별 사용법 안내(10단계), 상단 **튜토리얼**로 다시 보기 |
| 저장 | PDF: 원본 PDF 페이지는 벡터 그대로, 이미지는 원본 파일 그대로 넣어 화질 유지 (자르기도 원본을 남긴 채 가림) |
| 이미지 저장 | PNG·JPG, 현재/모든/선택/지정 페이지(여러 장은 ZIP 하나), 96·150·300 dpi, PNG 투명 배경(페이지 빈 곳만 / 흰색 부분 모두), 나눠 불러온 긴 파일은 하나의 긴 이미지로 합치기 (세로 32000px 한도, 넘으면 해상도를 자동으로 낮춤) |

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D | 복사 / 잘라내기 / 붙여넣기 / 복제 |
| Delete | 선택 요소 삭제 |
| 방향키 (Shift) | 1pt (10pt)씩 이동 |
| Ctrl + 마우스 휠, Ctrl+= / Ctrl+- / Ctrl+0 | 확대 / 축소 / 화면 맞춤 |
| PageUp / PageDown | 이전 / 다음 페이지 |

## 내 PC에서 실행

`run-local.bat`을 더블클릭하면 브라우저가 열립니다. (Python 필요 — 이 PC에는 설치되어 있음)
`index.html`을 바로 열면 브라우저 보안 정책 때문에 동작하지 않습니다.

- 편집하는 동안 **검은 창을 닫지 마세요.** 닫으면 PDF 열기·저장에 필요한 파일을 불러오지 못합니다.
- 편집기를 업데이트한 뒤 화면이 이상하면 **Ctrl+F5**로 새로고침하세요. (`serve.py`는 캐시를 막지만, 예전 방식으로 실행했을 때 남은 캐시가 있을 수 있습니다)
- 템플릿·추가 폰트는 브라우저에 저장되므로 `localhost`와 GitHub Pages 주소에서 따로 관리됩니다.

## GitHub Pages로 배포 (무료)

Git이 설치되어 있지 않아도 되는 **GitHub Desktop** 방식입니다.

1. [github.com](https://github.com)에 가입하고 로그인합니다.
2. [GitHub Desktop](https://desktop.github.com)을 설치하고 같은 계정으로 로그인합니다.
3. GitHub Desktop에서 **File → Add local repository** → 이 폴더(`C:\Users\USER\Desktop\J\AX\pdf-editor`)를 선택합니다.
   "저장소가 아닙니다"라는 안내가 나오면 **create a repository**를 눌러 그대로 만듭니다.
4. **Publish repository**를 누릅니다. 무료 계정은 공개 저장소에서만 Pages를 쓸 수 있으므로 **Keep this code private 체크를 해제**합니다.
   (공개되는 것은 편집기 코드뿐이며, 사용자가 편집하는 파일은 업로드되지 않습니다.)
5. github.com의 저장소 페이지 → **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → Save
6. 1~2분 뒤 `https://<내 아이디>.github.io/pdf-editor/` 에서 열립니다.

코드를 고친 뒤에는 GitHub Desktop에서 **Commit → Push origin**만 하면 다시 배포됩니다.

### 입장 코드·이용 기록 (선택)
이름·입장 코드·한마디를 입력해야 쓸 수 있게 하고, 누가 PDF·이미지를 저장했는지 관리자 화면(`admin.html`)에서 보려면
구글 시트 + Apps Script 설정이 필요합니다 (무료, 약 10분). 순서는 [backend/README.md](backend/README.md)를 참고하세요.
설정 전(`js/config.js`의 주소가 비어 있을 때)에는 입장 팝업 없이 누구나 쓸 수 있습니다.

## 맑은 고딕에 대해

맑은 고딕은 Microsoft 폰트라 저장소에 넣어 배포할 수 없습니다. 대신 PDF를 저장할 때 사용자 PC의 폰트를 불러옵니다.

- Chrome·Edge: 처음 저장할 때 "글꼴 액세스" 권한을 물어봅니다. 허용하면 자동으로 처리됩니다.
- 권한을 거부했거나 다른 브라우저라면: 파일 선택 창에서 `C:\Windows\Fonts\malgun.ttf`(굵게는 `malgunbd.ttf`)를 선택하라는 안내가 나옵니다.
- 한 번 불러온 폰트는 그 브라우저에 저장되어 다시 묻지 않습니다.

## 폰트 추가

- **나만 쓰기**: 오른쪽 패널 **+ 폰트 추가**에서 TTF/OTF 파일을 넣습니다. 이 브라우저에만 저장됩니다.
- **모두에게 배포**: `fonts/` 폴더에 파일을 넣고 `fonts/fonts.json`에 항목을 추가한 뒤 배포합니다. 자세한 방법은 [fonts/README.md](fonts/README.md)를 참고하세요. (재배포가 허용된 폰트만 넣어야 합니다)

## 알려진 제한

- 원본 PDF에 이미 있는 글자를 직접 고칠 수는 없습니다. 흰 네모로 가리고 새 텍스트를 올리는 방식으로 수정합니다.
- 암호가 걸린 PDF는 열 수 없습니다.
- Word·PPT·한글(hwp/hwpx) 파일은 바로 열 수 없습니다. 각 프로그램에서 PDF로 저장한 뒤 열어 주세요 (열려고 하면 이 안내가 나옵니다).
- 원본 PDF의 주석(메모, 형광펜)과 입력 양식 필드는 저장되지 않습니다. 화면에도 표시하지 않아 결과와 똑같이 보입니다.
- 맑은 고딕은 Windows PC에서만 표시됩니다.
- 페이지 크기는 가로·세로 최대 5080mm(PDF 표준 200인치)까지 지정할 수 있습니다. 나눈 페이지를 합쳐 저장하면 이보다 길어질 수 있으며, Chrome·Edge에서는 열리지만 Adobe Acrobat 등에서는 잘려 보일 수 있습니다.

## 폴더 구조

```
index.html            화면
css/style.css
js/
  main.js             화면 동작(버튼, 패널, 단축키, 끌어다 놓기)
  commands.js         모든 편집 명령 (화면과 외부 API가 함께 사용)
  api.js              외부 연결용 API → window.PDFEditor
  state.js            문서 데이터, 실행 취소 기록
  canvas.js           편집 캔버스(Fabric.js)
  pageSize.js         규격·방향·배치 계산
  importer.js         PDF·이미지 불러오기
  exporter.js         PDF 저장(pdf-lib)
  imageExport.js, zip.js  PNG·JPG 저장, 여러 장 ZIP 묶기
  fontSubset.js       저장 시 쓴 글자만 남긴 폰트 생성(HarfBuzz)
  fonts.js, idb.js    폰트 관리, 브라우저 저장소
  templates.js        자주 쓰는 템플릿 보관
  tour.js             처음 사용 안내
  notice.js           공지사항 버튼·팝업
  blur.js             모자이크·블러 효과, 저장 시 페이지 이미지로 합치기
  thumbs.js           페이지 미리보기
  extensions/         확장 기능(AI 연결 등) 등록 위치
fonts/                배포용 폰트 + fonts.json (fonts/brand/: 로고 필기체 Dancing Script, OFL)
vendor/               외부 라이브러리 (버전 고정)
docs/                 기획서, 확장 가이드
admin.html, js/admin.js  관리자 화면 (입장 코드 변경, 이용 현황, 공지사항 등록)
js/gate.js, js/config.js 입장 팝업·이용 기록, 기록 서버 주소
backend/              구글 시트에 붙이는 기록 서버 코드(Code.gs)와 설정 방법
run-local.bat, serve.py  내 PC 실행용 (캐시를 막는 로컬 서버)
samples/              테스트용 긴 파일 (긴이미지 6350mm PNG, 긴PDF 5800mm) — 나눠 불러오기·합쳐 저장 확인용
```
